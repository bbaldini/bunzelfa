# 🧝‍♀️ Bunzelfa

Web app (PWA per iPhone) per mandare la letterina a Babbo Natale tramite la **Bunzelfa**, l'elfa personale.
Le letterine arrivano in un Google Sheet (un foglio per persona) e si leggono dalla dashboard sul Desktop.

- `index.html`, `styles.css`, `app.js`, `config.js`, `sw.js`: l'app (GitHub Pages)
- `apps-script/Code.gs`: la casella postale (Google Apps Script legato al foglio)
- `dashboard/letterine.html`: la dashboard (la copia con le chiavi vive solo sul Desktop)

**Installare sull'iPhone:** apri il link in Safari → Condividi → «Aggiungi alla schermata Home».
